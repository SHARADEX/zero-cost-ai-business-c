How to Calculate ROI Formula

The Return on Investment formula is:

ROI (%) = ((Final Value - Initial Cost) / Initial Cost) * 100

Annualized ROI accounts for the compounding effect over multi-year periods:

Annualized ROI = [((Final Value / Initial Cost) ^ (1 / Years)) - 1] * 100
